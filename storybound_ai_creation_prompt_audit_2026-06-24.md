## UI Flow

The new-task page has two material modes:

- `粘贴文案`: user pastes an existing script.
- `AI 创作`: user enters a keyword; the app searches/retrieves reference material, calls LLM to create an original short-video narration draft, writes the generated text back into the main script textarea, then switches back to paste mode.

The visible AI creation tab text is:

- Title: `AI 创作`
- Description: `输入关键词，AI 自动搜资料并创作原稿`
- Keyword placeholder: `例如：钱学森回国 / 张桂梅 / 苹果秋季发布会`
- Extra requirements placeholder: `例如：字数控制在 500 字左右；聚焦人物的转折经历；语气偏感性`

Data source toggles:

- `全网搜索`: `从 Bing + 搜狗抓取相关文章作为参考素材`
- `AI 内置知识补充`: `允许 AI 用自己脑子里的知识补全细节（适合著名人物/历史事件）`
- `IMA 知识库`: reads `ima.client_id`, `ima.api_key`, `ima.kb_id`, `ima.kb_name` from local config.

In `index-DGyecVzc.js`:

- `tH({ track, onGenerated })`: React component for AI creation.
- `aE(options, materials, signal)`: builds prompt and calls LLM.
- `U9(trackName, trackTag, useAiKnowledge, hasReferenceMaterials)`: builds system prompt.
- `B9(options, materials)`: builds user prompt.
- `F9(text)`: post-processes LLM output.
- `h9(keyword, signal)`: Bing search.
- `E9(keyword, signal)`: Sogou search.
- `O9(url, signal)`: fetches selected article and extracts title/content.

- `fs(llmOptions)`: retry wrapper around raw LLM call.
- `ps(llmOptions)`: raw LLM call.

## LLM Call Parameters

`aE()` calls:

```ts
fs({
  system,
  user,
  signal,
  temperature: 0.8,
  maxTokens: 32768,
  timeoutMs: Qs(user.length),
  maxRetries: 2,
});
```

`ps()` loads the active LLM profile/config, then:

- Anthropic protocol:
  - endpoint: `${baseUrl}/messages` or `${baseUrl}/v1/messages`
  - body: `{ model, max_tokens, system, messages: [{ role: "user", content: user }], temperature? }`
- OpenAI-compatible protocol:
  - endpoint: `${baseUrl}/chat/completions` or `${baseUrl}/v1/chat/completions`
  - body: `{ model, messages: [{ role: "system", content: system }, { role: "user", content: user }], temperature?, max_tokens? }`

Retry behavior:

- `fs()` defaults to up to 5 retries, but AI creation passes `maxRetries: 2`.
- Retries HTTP `429/500/502/503/529`, network/timeout errors, and truncation errors.

## System Prompt

Generated by `U9(trackName, trackTag, useAiKnowledge, hasReferenceMaterials)`.

For the default story track, `trackName = 人物故事`, `trackTag = 纪实人物`, so the prompt becomes:

```text
你是一名资深短视频文案创作者，擅长创作原创短视频口播稿。

【当前赛道】人物故事（纪实人物）

【素材策略】{strategy}

【创作要求】
1. 必须是**原创口播文案**：不要直接复述参考素材的句子，要重新组织视角、节奏、叙事
2. 风格匹配赛道："人物故事"——按这个赛道的典型表达方式来写
3. 结构紧凑：开头要钩子（3 秒内勾住注意力），中间有起伏，结尾留余味或转发动机
4. 口语化：避免书面语、长难句、生僻词；适合用配音朗读
5. 不要标题、不要章节符号、不要 markdown，直接输出正文段落
6. 不要使用「以下是」「我为你创作」之类的开场白，直接给文案

【硬约束】
- 输出**仅文案正文**，不要任何解释、说明、问候语
- 不要使用 emoji 表情符号
- 不要出现"参考资料""根据上述""综合以上"等元描述{extra}
```

`{strategy}` has three variants:

```text
严格基于用户提供的参考素材进行创作，不要引入素材以外的信息，不要主观臆断或编造细节
```

```text
主要参考用户提供的参考素材，可适当结合你已知的可靠信息补全细节，但补充内容必须是确定的事实
```

```text
请基于你对该人物/主题的已知知识进行创作
```

When there is no external reference material, `{extra}` is appended:

```text
 - 本次无外部参考素材，请只输出确定的事实，对不确定的细节宁可省略也不要编造
```

## Search And Retrieval Logic

HTTP fetch helper:

- Function: `cg(url, signal, timeoutMs = 30000)`
- Tauri command: `http_request`
- Headers:
  - `User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0.0.0 Safari/537.36`
  - `Accept: text/html,application/xhtml+xml,application/xml;q=0.9,image/avif,image/webp,*/*;q=0.8`
  - `Accept-Language: zh-CN,zh;q=0.9,en;q=0.8`

Bing:

- URL: `https://cn.bing.com/search?q={keyword}`
- Before search, strips suffixes like `故事`, `生平`, `简介`, `资料`, `介绍`, `经历`, `传记`, `传奇`, `一生`, `事迹`, `信息`.
- Parses `li.b_algo`.
- Keeps up to 15 results.
- Drops Bing/Microsoft/self pages and URLs with too-short paths.

Sogou:

- URL: `https://www.sogou.com/web?query={keyword}`
- Parses `h3 a[href]` where href starts `/link?url=`.
- Resolves redirects by fetching the Sogou redirect page with an 8s timeout.
- Keeps up to 10 results.
- Drops Sogou/login/passport pages.

Search UI:

- Runs Bing and Sogou concurrently with `Promise.allSettled`.
- Deduplicates by URL.
- Marks video-like URLs (`douyin`, `xigua/ixigua`, `bilibili`, `youtube`, `v.qq`, `youku`, etc.).
- Auto-selects the first 5 non-video article results.

Selected article fetch:

- Function: `O9(url, signal)`
- Fetches page HTML with `cg()`.
- Extracts title from `<title>` or `<h1>`.
- Content container priority:
  - `article`
  - `.article-content`
  - `.article`
  - `.content`
  - `.main-content`
  - `#js_content`
  - `.rich_media_content`
  - `.post-content`
  - `.entry-content`
  - fallback: `body`
- Extracts leaf `<p>` text.
- Drops paragraphs shorter than 20 chars and boilerplate matching:
  - `版权所有`
  - `本文转载自`
  - `更多精彩内容`
  - `扫码关注`
  - `关注我们`
  - `点击关注`
  - `未经授权`
  - `责任编辑`
  - `声明：`
  - `来源：`
  - `原标题：`
- Joins paragraphs with spaces and truncates to 3000 chars per article.
- Fetch concurrency for selected articles: 3.

## IMA Logic

IMA base URL: `https://ima.qq.com`

Request helper:

- Function: `ug(path, body, creds, signal, timeoutMs = 20000)`
- Tauri command: `http_request`
- Method: `POST`
- Headers:
  - `ima-openapi-clientid`
  - `ima-openapi-apikey`
  - `Content-Type: application/json`
- Requires `code === 0`; otherwise throws `ImaApiError`.

Knowledge search:

- Endpoint: `openapi/wiki/v1/search_knowledge`
- Body:

```json
{
  "query": "{keyword}",
  "cursor": "",
  "knowledge_base_id": "{kbId}"
}
```

Expansion:

- If `highlight_content` exists, use it directly.
- If `media_type === 11` (note), call:
  - `openapi/wiki/v1/get_media_info`
  - then `openapi/note/v1/get_doc_content` with `target_content_format: 0`
- For file/URL-like entries, call `get_media_info`, then fetch `url_info.url` with `url_info.headers`.
- Downloaded IMA content is truncated to 50000 chars.
- IMA expansion concurrency: 3.

## Post-processing

- trims whitespace

- strips leading boilerplate matching:
  - `以下是`

  - `好的,` / `好的，`

- trims again
