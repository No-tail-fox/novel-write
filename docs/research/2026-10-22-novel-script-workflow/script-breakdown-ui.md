# 剧本拆解展示与资产提取顺序

日期：2026-10-22。

## 当前问题与判断

单集剧本候选已包含人物、造型、场景、道具及分幕分场。此前审核界面只在场次列表底部展示三行实体名称，长标题和梗概又挤占阅读区，造成“没有拆解”的观感。

此前正式制作资产随分镜审核应用才进入项目，提取展示与跨集身份确认没有形成明确的前置步骤。现已将项目资产独立，并在批准剧本时确认和保存身份；完整设计、实现范围和概念图见[项目资产与分集制作](../../design/2026-10-22-motion-comic-assets/README.md)。

依据[原有固定提交调研](README.md#github-成熟方案对照)，项目的具体提取时点不同，但文字定义应在分镜与媒体制作前抽取、核对和复用。建议目标顺序为：

> 原文与分集计划 → 人物/地点/道具提取 → 单集剧本、分幕分场及实体补充 → 审核与跨集身份统一 → 分镜 → 定妆/参考图 → 视频、配音与合成。

人物表和视觉参考图应分开处理。前者可以早期提取，后者在定义确认后按需生成；分镜文本和参考图可按制作方式调整先后。幕数沿用剧本结构，不强制三幕。

## 本次实现

- 剧本审核新增“分幕分场 / 人物 / 场景 / 道具”页签及数量，分幕分场按幕分组。
- 人物可查看身份、别名、性格、声音和各套造型；场景和道具可查看描述、视觉定义。
- 场景依据已有 `locationKey` 展示引用场次，点击可回到场次正文。
- 梗概默认折叠，阅读区设定最低高度；分集列表、场次列表和正文独立滚动，小窗口保留编辑区滚动和底部操作栏。
- 项目顶层新增「分集制作 / 项目资产」，人物、地点、道具跨集共用，并可在分镜前进入项目库。
- 单集候选人物、造型、地点和道具支持自动匹配、显式复用或新建。批准时确认并持久化稳定身份；同名歧义阻止批准，分镜生成和应用再次检查身份。
- 资产详情按稳定 ID 汇总已确认剧本与正式分镜的跨集引用，可跳转到对应分集；失效批准记录被排除，读取失败时保留正式分镜引用。
- 参考图采用大图和版本条，切换预览与固定版本分开；固定、取消固定、文件错误及重试均有对应状态。人物定义可折叠，优先保留造型参考的可见区域。
- 空人物/道具列表有明确状态；切换拆解页签不会丢失已编辑的剧本草稿。

项目库可编辑统一定义，单集候选可选择身份映射。当前按集提取和补充资产，未新增整部小说的一次性全剧预提取；自动匹配仅使用名称与别名精确匹配，不做模糊合并。道具仍由后续分镜的 `propKeys` 绑定，不从正文猜测场次归属。
