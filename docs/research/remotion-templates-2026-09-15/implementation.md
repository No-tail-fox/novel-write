# VOX 动画接入记录（2026-09-15）

已接入生产页面：**VOX → 分镜 → 画面 → 动画**。使用 Remotion 4.0.524，提供「动画模板」与「AI 生成动画」两个独立入口。

## 已实现

- 49 个本项目参数化模板，覆盖纸张拼贴、证据讲解、时间叙事、对比分析、数据解释、地图叙事、原理流程、书籍推荐、文字与图片、音频与字幕、转场与标注。完整目录以 `src/shared/vox-animation.ts` 的 `VOX_TEMPLATES` 为准。
- 模板分类、搜索、文字/数据/颜色/焦点参数编辑；直接导入本地图片、书封和音频，音频加入项目声音时间线。
- 地图采用本地 Natural Earth 底图，支持经纬度路线、镜头聚焦和用户提供的区域 GeoJSON。历史路线由用户数据决定。
- 书封、阅读收获、摘录、书单、目录及围绕书脊翻转的 CSS 3D 书页；后者需要封面与至少一张内页。
- 真实音频波形/频谱，遵循声音时间线的片段起点、裁剪与静音；字幕和歌词使用项目已有的时间戳。
- AI 使用设置中的文本模型生成或修改 TSX；支持查看源码、编译诊断、取消请求、失效结果保护。模板/代码草稿分开保留。
- 个人模板本地保存、重开和删除；跨项目使用时，缺失的图片/音频需重新选择。无演示书单、虚构数据或预设生成任务写入用户项目。
- 当前动画镜头可另存 MP4；完整项目可混合动画、原有拼贴、AI 视频镜头导出。字幕、音频使用同一时间线；支持取消导出。
- 编辑器 iframe 隔离运行，限定代码依赖和资源来源；导出重新编译源代码，不信任项目中缓存的编译产物。

## 验证证据

- 49 个模板 × 横屏/竖屏：98 次实际浏览器加载、寻帧与截图。
- 1536×1024 与 1040×720：模板搜索、参数修改、个人模板保存、双模式切换、生成代码桩、单镜头导出按钮、错误代码提示与恢复原文后重新预览，无浏览器运行时错误。
- 实际 Electron 渲染 8 秒 1920×1080、24 fps 混合视频：内置模板、书页翻转、有效 TSX 组件、原有拼贴；含音频和字幕。全部 192 帧解码成功，4 个镜头的字幕测量、时间边界、字形与安全区均通过。另验证了渲染中途取消、隐藏窗口清理及随后成功导出 2 秒单镜头。
- 111 项相关回归通过；全套所选测试仍有一项既有失败：`music-mv:update` 主进程接口缺失。一次在并行渲染时发生的批处理测试超时，独立复跑通过。
- `npm run build` 与独立配置的 Electron 启动冒烟测试通过（主进程、preload、IPC、壳层及窗口策略）。
- 类型检查无本功能新增错误；原有 browser fallback 缺少 `updateHtmlVideoSceneStructure` / `updateMusicMvTask`，以及存储测试调用缺失 `updateMusicMvTask`，仍使全项目类型检查失败。
- AI 验证使用本地固定响应，未调用付费模型。本轮没有将上游列表中全部 163 个项目或 157 张配方称作已安装模板。

证据位于 `.artifacts/vox-animation-qa/`：`browser-report.json`、`browser-ui-final-report.json`、`render-report.json`、`decode-report.json`、正常/紧凑截图及 `vox-animation-integration.mp4`。

## 使用范围

模板是根据研究实现的本项目组件，外部样例照片、书摘和非商业许可证模板未嵌入。Remotion 引擎许可独立于模板许可，详情见 `src/features/vox-animation/THIRD_PARTY_NOTICES.md`。

转场模板在镜头内部作用于前后素材，保留项目剪切时长。动画镜头可复制并调整时长；结构面板不直接拆分/合并动画，防止丢失另一段动画内容。单镜头 MP4 保存到用户选择的位置，完整成片继续使用原有成片历史。
