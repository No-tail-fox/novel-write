# AI 漫剧生成集成实施

用户授权：接入 Jellyfish、shuohao 的适用模块并完善漫剧生成，视频只使用远程 API。

## 阶段
- [complete] 结构化剧本、角色/资产、分镜与确定性校验，带上游许可和来源。
- [complete] 远程视频任务、状态恢复、输入过期保护、视频资产与成片渲染。
- [complete] 导演台编剧/分镜操作、远程模型选择、视频预览和恢复。
- [complete] IPC、持久化与整体整合。
- [complete] 聚焦测试、类型检查、构建、双主题桌面 UI 与本地媒体验收。

## 验收结果
- 结构化规划采用“先生成草案、预览、显式应用”的两阶段流程，支持追加新集与受保护替换。
- 远程视频提交会先持久化任务 ID；付费 POST 不自动重试，旧任务只按原 Provider 和任务 ID 恢复。
- 视频输入指纹覆盖系列规则、角色造型、场景、道具、固定参考图、首尾帧、时长、画幅、Provider 与模型；变更后旧结果保留为未选中历史并阻止导出。
- 成熟流程采用“剧本导入 → 分集拆解 → 分幕分场 → 角色资产 → 分镜图 → 远程视频 → 配音合成 → 成片导出”；人物、场景、道具均支持人工补录。
- Electron mock QA 覆盖 1536×1024、1040×720、深色与浅色主题，共 60 张截图；无横向溢出、控件裁切或运行时错误。
- 原浅色 QA 只切换根节点、没有同步 Fluent Provider；现已改为真实持久化主题切换，并同时断言根节点与 Provider 主题后重跑通过。
- 验收期间对隔离域名 `qa-video.invalid` 的请求数为 0，未调用任何真实付费 API。

## 约束
- 保留当前大量其他未提交改动，只修改必要接点。
- 禁止部署本地视频模型，禁止静默把远程视频失败伪装为图片动画成功。
- 凭据留在用户设置/运行时；不写源码、不打印。
- 实施与模拟 API 验收已授权，不需要再次询问；实际付费模型调用先核实单价和可用模型。
- 重生成采用可预览草案和显式应用，避免覆盖旧项目、已有媒体及用户编辑。
- 每个子任务独立文件所有权，共享边界由主任务整合。
