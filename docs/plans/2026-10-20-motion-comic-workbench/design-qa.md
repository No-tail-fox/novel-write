# 漫剧工作台改造与验收

## 配置核对

用户本地权威数据库启用的图片配置为 **GPT Image / gpt-image-2.5 / VllmProxy**。本次只读取模型配置和凭据存在状态，未解密或输出密钥。配置状态不等于远端服务实测通过。

## 已完成

- 资产页分为角色、场景、道具、系列设定，默认进入角色定妆图。分区保持挂载，切换不清空编辑草稿。
- 左侧显示资产生图模型、配置状态、质量与分辨率、固定参考的进度及实际缺项。
- 角色、场景、道具可直接生成参考图；调用既有图片服务，成功后保存版本、自动固定并通过项目保存队列写入。
- 同角色支持新增造型和连续性要求编辑；生成新造型使用同角色固定参考，模型不支持参考图时给出明确提示。
- 参考生成分别采用定妆图、场景空镜、单一道具提示和画幅，不追加默认海报封面样式。
- 生成期间的定义变更通过输入指纹拦截，旧结果保留在图片历史；失败不改变当前固定参考，可直接重试。
- 分场页显示真实镜头标题、景别、时长、画面、动作/运镜、人物造型、场景/道具、动作承接、对白与情绪。无对白明确标注可留空。
- 阶段导航增加真实状态明细。继续复用项目组件、语义 token、既有路由和滚动容器。

## 验证

- renderer / electron / scripts 三份 TypeScript 配置检查通过。
- Vite 生产构建与 Electron 构建通过。
- 8 个针对性测试文件共 **53 项测试通过**，覆盖参考生成输入、角色一致性、固定版本及来源、输入变更、历史容量和既有工作台逻辑。
- 隔离 Electron 使用本地 HTTP 图片桩，完全阻断外部请求。验证角色/场景/道具生成、一次失败后重试、保存重开、新造型输入变更保护及再次生成、缺少凭据时禁用入口。
- QA 使用 6 次本地请求，其中 2 次走参考编辑接口；未发生付费请求、未访问用户生产项目、未变更用户真实配置。
- 检查 1536×1024 与 1040×720、深浅主题、资产分区切换、正常保存与错误状态；页面无横向溢出，长内容由工作区内部滚动。
