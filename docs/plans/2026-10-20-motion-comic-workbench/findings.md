# Findings

- 权威数据库配置启用 GPT Image / gpt-image-2.5，baseUrl 为 VllmProxy；本地 vault 存在，未解密或输出凭据，未实测远端生成。
- 原角色资产页每个参考图只有本地导入入口，配置图片模型后仍需绕到其他页面生成再导入。系列设定长表单也挤占了角色视觉制作入口。
- 原阶段导航没有显示状态明细；分场页有概要但没有逐镜头制作内容预览。
- 采用 StoryDream 既有 Fluent 包装组件、语义 token、紧凑创作工作区。各资产分区保持挂载，切换时保留草稿和稳定 ID。
- 图片实验室默认 cinematic 样式会追加海报/封面构图提示，不适合定妆图。参考生成使用专用 reference 样式，并按角色/空镜/道具分别组织提示词与画幅。
- 新造型只复用同一角色的固定参考图；生成完成比较完整输入指纹，设定修改后结果保留在图片历史，不绑定新设定。
- 通用错误处理会隐藏普通 Error 的文字。新参考生成的定义缺失、失败、过期等情况改用 AppError，以展示可执行提示。
- 原分支已有产品流测试 4 项失败、共享组件导出计数测试 1 项失败；在未改动 HEAD 上复现，属于既有断言与实现不同步。本任务不改写不相关工作流以迎合旧断言。
