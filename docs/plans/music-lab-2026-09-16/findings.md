# 页面与实现发现

- 公开前端包括工作区、灵感生成、专业生成、声音、人声克隆、歌曲关联编辑、分轨结果及播放器。
- 参考站需要账号登录；API Key 不等于网页登录态。
- StoryDream 采用现有 Fluent 组件、珊瑚色、稳定面板；音乐创作放在素材区域，音乐 MV 保持项目制作角色。
- 可复用受管 BGM 和音频轨道；视频 Lab 的重启失败策略不适用于付费音乐任务。
- 已有 45 份供应商文档和接口分析存于 docs/research/suno-integration-2026-09-16。

- 用户登录的 Chrome 已核验，参考网站的「音色」是音效与循环采样，不等同于歌手人声克隆。两者在软件中分开设置。
- 高级表单实际包含歌词结构/拼音、排除风格、演唱偏好、时长、随机度、风格影响和多样性；公开整曲 API 没有硬性秒数参数，界面明确时长只是提示词引导。
- 人声歌曲查询结果在 data.items[]；强化上传 98% 通常仍处于媒体准备阶段。已对这些响应编写恢复测试。
- 共用网络策略原本过滤 Idempotency-Key，已允许该头并验证人声生成的幂等编号可以实际发出。
- 全局媒体 CSP 不允许直接播放云端 HTTPS 音频。音乐页通过已验证的下载接口保存本地再试听，复用现有 file 媒体权限；没有放宽整个应用的 CSP。
- 紧凑窗口中详情封面需要禁止 flex 收缩，避免长详情把封面挤成细线。修复后验证生成按钮与详情操作均可滚动到达。
