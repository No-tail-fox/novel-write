# StoryDream Web / Electron 重构

## 目标与当前阶段

用户希望清爽的网页版成为共享界面，桌面版承载相同页面；本地剪映、文件和渲染能力仍可使用。当前先完成概念图、边界审计和可运行的共享壳层，再按工作流迁移，不能把浏览器预览包装成完整网页版。

逐页布局、20 个旧视图迁移、对象语义、响应式规则、双端连接器、剪映交付、开发批次和验收矩阵以 [`2026-09-10-page-reconstruction-spec.md`](2026-09-10-page-reconstruction-spec.md) 为执行细则。本文件保留架构和阶段总览；两份文档冲突时，以详细方案中标明的当前代码事实和能力边界为准。

## 已核实的基础

- `src/main.tsx` 是 React renderer 入口，Vite 已可运行于浏览器。
- `AppShell` 现在给根节点标出 `data-runtime=electron|browser-fallback`，为后续 companion 状态和能力提示提供稳定 CSS/QA 钩子。
- `src/app/App.tsx` 通过 `window.storydream` / `window.storybound` 使用 preload API，没有 preload 时使用 `makeFallbackApi`。
- `browser-fallback.ts` 含模拟数据、浏览器存储与明确不可用能力，不能直接用作正式 Web 后端。
- `src/shared/storydream-api.ts` 提供现有业务合同；`electron/preload.ts` 与 `electron/main.ts` 承担 IPC 及本地操作。
- 剪映目录发现、草稿生成、pyJianYingDraft 桥接和启动剪映已有实现。启动应用不等于成功打开指定草稿。
- `src/styles.css` 约 7000 行，叠加共享壳层、特定页面和导演台样式；导演台还隐藏全局壳层并自带导航。因此仅换颜色不能解决层级和密度问题。

## 设计方向（首轮提案）

浅色中性灰白、石墨文字、少量珊瑚主操作，保留深色偏好。正文 14px、辅助信息 12px 起、工具标题 16px、页面标题 22px；间距使用 4/8/12/16/24/32，圆角 4/6/8px。创作预览可以用深色画布，参数区仍清晰可读。

项目外采用精简导航：项目、素材库、灵感、模板、任务、设置。各制作类型放在新建项目入口和类型筛选中，避免把 20 多个功能同时堆在侧栏。账户与设备放在底部入口。最终迁移须保留全部旧路由可达。

项目内采用顶栏 + 工作流页签 + 工作区。左侧镜头列表，中间预览及时间轴，右侧当前镜头属性；高级参数按需展开。编辑器中保留回到项目和未保存离开保护。文案页、素材库、任务、设置分别复用表单、集合、列表和分区表单布局。

概念图只用于布局与视觉沟通，图中项目为示意内容，不代表用户数据或已完成界面。

## 双端架构

共享层：`src/app`、`src/features`、`src/ui`、领域模型和可在浏览器执行的纯函数。运行环境通过 adapter 提供业务 API、能力描述、媒体 URL 和事件订阅。

桌面：同一份构建产物在 Electron 中加载；IPC adapter 调用本地服务。桌面打包内置版本化页面，不直接给远程网页开放 Node 或宽泛 IPC。

浏览器第一阶段：由本机连接器同时提供页面和受控 API，浏览器访问本机地址。这样首先实现本机数据、FFmpeg 与剪映可用的真实浏览器工作区，并绕开公网 HTTPS 网页访问本地服务的兼容性问题。它不等于公网或多用户服务。

浏览器第二阶段：远程 Web API 负责项目、任务、生成、对象存储和密钥保管；同一份页面增加身份、租户、配额和作业恢复。云端不能直接读用户磁盘。

远程网页连接本机：先由用户显式配对，连接器校验精确 Origin/Host、短时凭证与操作能力。仅绑定 loopback，默认关闭；HTTP 接口不透传任意 IPC，不允许客户端传入任意命令或任意文件路径。浏览器混合内容、CORS、Local Network Access 权限需逐浏览器验证，不能承诺所有环境透明可连。若浏览器限制阻断，采用出站配对连接或草稿包下载导入。

## 剪映交付

| 环境 | 交付路径 | 验收要点 |
|---|---|---|
| Electron | 本地生成草稿，确认目录后打开剪映 | 草稿和素材存在；启动成功单独报告 |
| 本机浏览器 | 本机 API 调用同一交付服务 | 配对/断线、任务状态和目录权限 |
| 远程 Web + 连接器 | 下载受签名/受限 manifest，校验文件后写入指定草稿根目录 | 路径穿越、覆盖、失败回滚、hash 校验 |
| 远程 Web 无连接器 | 下载可迁移草稿包或成片，用户导入 | 草稿绝对路径重写、媒体齐全、版本兼容 |

草稿打包不是把现有文件夹简单 zip：必须处理本机绝对路径、素材引用、重名、磁盘空间、半成品清理和剪映版本差异。

R1-R9 的总阶段如下；每阶段的子任务、依赖、回退方式和发布门槛见[详细页面重构方案](2026-09-10-page-reconstruction-spec.md)。

|---|---|---|---|
| R0 | 审计入口/路由/状态、生成项目与编辑器概念图 | 图片可打开；能力边界有证据 | 完成首轮，设计反馈待收集 |
| R1 | 统一 tokens、精简共享壳层、独立 Web 启动入口 | 双主题/双尺寸、所有旧路由和离开保护有效 | 基础已验证，导航重组待迁移 |
| R2 | 项目集合与新建流程 | 搜索/类型/归档、空态、创建及重开；没有模拟状态冒充真实结果 | 进行中：P02 首轮、R2.1 500 项管理与重开通过；各类型创建草稿/失败恢复待收口 |
| R3 | 导演台三栏与阶段导航 | 选择、属性、播放、字幕、时间轴与未保存状态一致 | 待办 |
| R4 | VOX、漫剧、HTML、MV 逐页迁移 | 每种类型完成创建/保存/恢复/生成/交付流程 | 待办 |
| R5 | 资源、模板、队列、设置迁移 | 搜索/导入/错误/分页/返回路径与主题一致 | 待办 |
| R6 | 拆分本地服务与受控 HTTP adapter | 合同验证、取消/恢复/事件隔离、媒体访问授权 | 待办 |
| R7 | 本机 Web + 剪映连接器 | 浏览器真实生成/本地交付、断线恢复与完整性验证 | 待办 |
| R8 | 公网服务及部署形态 | 身份/租户/云存储/密钥/成本/跨设备明确后实施 | 待办 |

R0/R1 可先推进；远程产品范围在 R6 前再定，不影响当前界面设计。已有长片、字幕时长与质量专项代码继续保留，真实 AI 多镜头语义抽检、批次恢复和 provider 样片作为后续产品验收项合并。

首轮图片、已落地范围、验证和生成记录详见 `docs/design/storydream-web-redesign/review.md`。当前不是完整网页版交付，概念图中的项目入口和编辑器仍待实现。

## 验证尺寸

桌面 1440x900、紧凑桌面 1024x768，网页另加 768x1024 和 390x844。窄屏以项目浏览、正文编辑与任务管理为主；编辑器通过选择面板切换，禁止把三栏强压到一屏。检查文字裁切、横向溢出、焦点、可达操作、滚动归属和真实媒体加载。
