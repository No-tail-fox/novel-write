# 爆款拆解模板提炼设计

## 目标

爆款拆解完成后，页面先展示拆解报告，不再把“生成同款视频任务”作为唯一默认出口。用户可以在结果页主动选择后续动作：

- 保存为故事模板 + 图片模板
- 生成新任务

保存模板时必须允许用户设置新模板名。系统可以给出默认建议名，但故事模板名和图片模板名都要可编辑，空名称不能保存。

## 产品行为

### 结果优先

爆款拆解流程完成后，结果页继续展示现有拆解内容：

- 开头类型、分析和可复用模式
- 结构类型、节奏和大纲
- 结尾类型、功能和可复用模式
- 爆点总结、证据和可复用模式
- 原文案转写
- 关键帧提示词拆解
- 结构级复刻草稿

“复刻功能”区调整为“后续操作”区，提供两个并列动作：

- 保存为模板
- 生成新任务

### 保存为模板

点击“保存为模板”后显示一个轻量表单，默认填入：

- 故事模板名：`爆款故事模板 - {标题或主题}`
- 图片模板名：`爆款图片模板 - {标题或主题}`

用户可以修改这两个名字。保存时创建：

1. 故事模板
   - 类型：`PromptTemplate` 的 `task`
   - 来源：自定义模板
   - 默认赛道：当前拆解配置的赛道
   - 默认图片模板：本次新建的图片模板
   - 内容：沉淀开头、结构、结尾、爆点逻辑，并明确禁止照抄原文、标题和独特表达

2. 图片模板
   - 类型：`CustomStyle`
   - 来源：关键帧画面拆解
   - 字段：`prefix`、`suffix`、`negativePrompt`、`description`
   - 内容：沉淀构图、镜头、氛围、文字覆盖、关键元素和画面风格

保存成功后展示反馈：`已保存故事模板和图片模板，可在提示词模板中继续编辑。`

### 生成新任务

“生成新任务”沿用现有爆款复刻任务逻辑。它读取拆解结果里的结构级复刻草稿、关键帧提示词参考、赛道、风格、比例和草稿模板，创建并运行一个新任务，然后打开任务详情。

## 技术切分

### 类型和纯函数

在 `src/shared/viral-analysis.ts` 增加一个纯函数，把拆解结果转换为模板草稿：

- 输入：`ViralAnalysisResult`、故事模板名、图片模板名、赛道、风格、草稿模板、时间戳和可选 id
- 输出：`PromptTemplate` 和 `CustomStyle`

函数保持无副作用，方便单元测试，也避免把模板提炼逻辑散落在 React 组件里。

### Renderer

`ViralAnalyzerPage` 继续负责读取拆解结果和创建新任务。新增保存模板回调：

1. 校验故事模板名和图片模板名
2. 调用模板提炼纯函数
3. 依次调用已有 `api.savePromptTemplate` 和 `api.saveCustomStyle`
4. 刷新状态并提示保存成功

`ViralReport` 增加模板命名表单和保存状态。表单默认展开或点击“保存为模板”后展开均可，关键是用户能看到并编辑两个模板名。

### 存储和 IPC

现有接口已经支持：

- `prompt-template:save`
- `custom-style:save`

本功能不需要新增数据库表，也不需要新增 IPC 通道。

## 边界

- 本次不新增独立“爆款模板库”，直接复用现有“提示词模板”里的故事模板和图像模板。
- 本次不改变下载、抽帧、转写、拆解流程。
- 本次不自动创建新视频任务，必须由用户点击“生成新任务”。
- 本次不做模板市场、分享、评分和云端同步。
