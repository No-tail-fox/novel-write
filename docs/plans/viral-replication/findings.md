# 方案决策与事实

- 用户最终纠正：主目标是整条视频的整体拆解。先前侧重短口播和复刻生成的规划已修订；默认全片，内容、镜头、构图/运镜、字幕、转场/动效、声音与音画节奏都需独立结果。
- 用户已确认可对外收费分发；20–30 秒只作为后续 M2 样片，A 为首片，再生成 B/C，共三个版本。
- 原片全时长流式扫描与分批理解；30 秒核心窗口及 64 帧/16 单元/16 初始视觉请求仅单批预算，不是整片限制。长片分片持久化，逐轨覆盖有缺口不能称为整体完成。
- 整体拆解 reference revision、人工蓝图 revision、后台 runGeneration 独立；原始报告固定快照，人工编辑通过 CAS 发布当前指针。
- 原片台词、声音和视觉分析不能互相冒充；实际消费连续视频/音频的能力要有记录。低清、无音轨、混合声音与未知动作分别记录限制。
- 导演固定 24 fps；模板 24/30 测试不等于已有产品 30 fps 导出。ShotCraft v1 是整镜时钟，标题/纸卡内部事件需 revision 2；选择性字幕强调需补 schema 和两条渲染路径。
- 本地 B-roll 需独立 local-video 接口；不能伪造 image-to-video job 或使用未完成 hybrid。工程各自持有素材副本，按 hash 复用产物，不新增共享 blob 回收系统。

- 现有爆款输入/抽帧/转写/分析/再创作已有任务和 checkpoint，旧版本兼容必须纳入。
- 导演工程已有 EditorialCollagePipelineData、素材版本、字幕 tokens、音频时间线与导出；应明确映射而非另建播放器/存储。
- Hypit 已核实版本0.1.10、提交98000342cc222392ac8813cca2f1977c979821a8。没有自动视频分析接口；跨build复用及预算需要主应用管理。
- 现有字幕工具区分 provider/whisper/manual/estimated；语义定位不能把估算标成声学实测。
