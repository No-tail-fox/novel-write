# 交叉审查定案

2026-09-16。最新用户纠正优先：用户要整条视频的全维度拆解，不能把短口播复刻当作主体。M1 必须覆盖整片的内容、镜头、构图运镜、字幕排版、剪辑转场、动效、声音及关联节奏。20–30 秒仅用于 M2 生成验收。

- 完整拆解默认全片 [0,durationMs)，不设 10–120 秒选段上限，不强制只分析口播；可选区间仅为用户主动聚焦。无 720p 门槛或 1 GiB 产品硬限制；文件大小、空闲磁盘、解码能力和预计工作量真实预检，资源不足说明缺口。
- 快速概览仍默认 8/最多 40 帧。完整拆解使用全片局部检测＋分批视听理解＋跨批次合并：单批核心范围初始最长 30 秒，前后各 1 秒上下文；64 唯一帧、16 观察单元、每单元4帧/1次视觉请求均是单批资源上限，绝非全片上限。超限继续拆批，不能合并/丢弃实际镜头以满足数量。全片预算在扫描之后按批次数汇总，预算不足暂停并保留未分析轨道/区间。视觉并发 1，自动付费重发 0，显式重试新增预算且计入累计。
- 完整拆解字段必须有 shot、track event（visual/action/camera/composition/text/transition/motion/speech/music/sfx）、source evidence、音画关系及 coverage matrix。不把 ASR 代替所有音频分析；音效/配乐需真实音频证据，模型无法确认时待复核。
- 首片 1080×1920、24 fps。30 fps 仅用于求解器/模板夹具，产品 fps 选项在后续扩展。
- A 是首片，新增 B/C，共 3 个输出，不另增第四条。
- 人工同步门槛以 acceptance A05 为准：三个版本至少 12 个独立人工标注锚点，中位误差 ≤120 ms、最大 ≤250 ms；算法帧量化另 ≤1 帧。
- M2 阶段可先验收整镜模板静态样片，但宣布 M2 完成前须包含标题/纸卡 revision 2 内部语义标记（P09）、整镜 local-video B-roll（P10）、三变体（P11）和完整 QA（P12）。不含其他四模板的内部语义标记或多视频图层。
- M2 媒体采用每工程独立副本；内容 hash 和来源记录表达复用，不建新的共享 blob/引用计数/全局 GC。复制字节不算 Provider 重生成。
- 所有原片证据存原文件绝对毫秒；ASR 区间局部时间仅在适配层加一次 audioOriginMs。回放直接 seek 证据时间，不再叠加起点。
- 数据主类型文件为 viral-replication-contract.ts。报告 schema v2 引用生成快照；当前蓝图 schema v1 独立 immutable JSON + DB 指针。工程 replication 块和派生运行记录需给出具体字段及 IPC，不能相互转引到不存在的定义。
- 锚点首期支持段落边界、精确 UTF-16 字符范围及显式 edge/offsetMs；新增语义事件的 in/hold/out 和 priority、素材槽依赖/选中版本、变体范围锚点覆盖要与导演求解器保持一致。

统一实施编号 P01–P14，详见 implementation-plan.md。
