## 7. 详细任务清单

### E01 / 前置：稳定工作与运行环境

- 现状：C 盘满、I 盘极低空间；工作树包含大量既有产品改动和无关用户文档。
- 工作：确定源码、缓存、QA、打包和应用数据各自目录；构建/导出前测实际目标卷容量；空间不足时提前报错。建立本轮源码和证据基线，避免历史报告覆盖最新报告。
- 范围：构建/测试/QA 脚本、输出路径配置和运行前检查；不把删除用户文件作为自动动作。
- 依赖：无；可在整理已授权目录/配置时独立推进。当前 QA 已迁到 E，其他部分待做。
- 验收：普通构建、样例导出、失败日志能写入；低空间注入返回明确路径与剩余容量；无需猜测某个失败是否由磁盘导致。

### R01 / P0：统一草稿、未保存状态与离开行为

- 工作：为项目、模板、设置、MV、HTML 文案/场景、对标备注、试听输入明确草稿所有者；覆盖返回、全局路由、项目/场景选择、新建和窗口关闭。
- 实现：适合自动保存的内容保存可恢复草稿；配置提交保留明确“保存”语义；需要舍弃时提供保存/放弃/取消；顶栏不再把 UI 偏好保存表述成所有内容已保存。
- 范围：`App/AppRoutes/AppShell`、各页 draft state、HTML 编排器；复用已有新建任务和绘图草稿机制。密钥不能用明文 localStorage 保存。
- 依赖：E01；与 R02/R03 协同。
- 验收：六类稿件切页重返不丢；导演切项目、HTML 切场景保持正确稿；取消离开原位保留；保存失败不清 dirty；关闭重启恢复策略明确且可测。

### R02 / P0：阻止旧异步结果覆盖当前对象

- 工作：检查 VOX 保存、图片/语音/视频、两页 render 回读；HTML 保存/AI 创作等路径。每个请求绑定项目、集/场景、输入版本、请求代次。
- 实现：回包只归入发起对象；新输入保留；旧输出可记入历史但不能自动选中或清 dirty；成片关联发起时的不可变快照。沿用漫剧现有有效的输入保护。
- 范围：两导演页、`director-generation`、HTML 页面/编排器、相关主进程持久化契约。
- 依赖：E01；与 R01/R04 对齐。
- 验收：延迟 A 保存/生成，先编辑或打开 B，A 成功/失败都不改变 B；同 ID 新 revision 不被旧回包覆盖；同 revision 不同场景不串写；错误结果有可追踪历史。

### R03 / P1：设置与模板的加载/保存保护

- 工作：保存设置 A 期间输入 B 时保留 B；详情加载尚未完成时禁止假编辑或保护新编辑版本；区分选择变化与内容变化。
- 范围：`SettingsPage`、`ProviderProfileManagers`、`settings-controls`、两个模板页及 AI 字段生成回写。
- 依赖：R01 的状态契约，可独立于生成执行器开发。
- 验收：500ms 延迟详情和保存响应下立即改名称、地址、密钥、提示词、画布位置，内容不回退；保存并测试/启用/普通保存的行为一致；密钥待提交状态不被误清。
