## 实现

使用 ai 7.0.159 与 @ai-sdk/openai 4.0.106，运行环境为 Node.js 22+。Messages 保留 Claude Agent SDK 0.3.314。三个协议沿用同一套创意指导、受控文件工具、渲染审片与成片验收。

研究阶段建议的 ToolLoopAgent 在本次实现中收窄为逐轮 generateText：由 AI SDK 转换原生协议，Lemo 在每轮请求和整批工具之间写入持久记录。这样能保证完整回执和状态先落盘，再执行有副作用的工具；不让自动 execute 回调越过原有记录机制。

Chat / Responses 保存原生多轮消息（包含 Responses 的 reasoning 元数据）、后端版本、协议与输入/配置身份。恢复沿用原时限和请求账本。未知请求、未结算工具、不匹配身份均阻断；不自动重试、不跨协议续跑。审片返回实际图片，必须经过下一轮模型反馈才能完成影片。

启动失败在设置弹窗内展示，保留未保存要求；忙碌时阻止重复点击；关闭/保存后恢复焦点。能力不足时引导用户选择已验证的项目模型。费用说明明确区分 Messages 的 SDK 估算与新后端的请求数、令牌及时间限制。

## 试用步骤

切换到试用分支后，在仓库根目录执行：

```text
npm ci
npm ci --prefix services/lemo-agent-worker --ignore-scripts --no-audit --no-fund
npm run build:lemo-worker
npm run build
npm run dev
```

在系统设置中保存模型地址、模型名及协议，先免费检查配置，再主动执行 Lemo 能力验证（会产生真实服务商请求）。项目顶部选择同一模型，然后点击“按此风格创作全片”。

这不是任意模型的无条件兼容承诺：模型仍需支持工具、图片输入和多轮反馈。Chat / Responses 当前不提供美元费用上限；请求数、输出 Token、轮次、修复次数和总时限继续生效。
