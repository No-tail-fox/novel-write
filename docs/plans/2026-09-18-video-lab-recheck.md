# 素材库视频生成复核与修正

用户反馈上一轮仍不符合常见视频生成器的使用方式。本轮按模型选择、输入参数、素材引用、真实请求四条链路重新核对。

- [completed] 重新阅读现有页面、配置、上传 QA 与运行时，独立核对官方模型能力。
- [completed] 修正模型入口、H3 型号判断、参数约束、参考素材引导和人物库接入。
- [completed] 使用已配置多模型场景验证切换、素材保留和实际提交内容；完成类型、构建及两种窗口截图。

## 已确认的问题

- 页面仅列出已有服务配置，未提供明确的 H3 / Seedance 模型入口。
- H3 Max 检测使用 `/max/`，错误匹配 `MiniMax` 本身，普通 H3 丢失 2K。
- 时长允许 1 秒和小数，模型约束没有在服务端统一生效。
- 隐藏模式中的参考数量仍参与校验，切换为文本后可能被旧参考阻塞。
- 提示词按钮只追加空标题；图片用途说明与真实素材引用缺少可见对应。
- 人物参考无法直接选择已有的人物素材库。

## 验证记录

- 当前 QA 构建受本地 Rolldown 原生包缺少 package.json 阻塞，二进制本身存在；准备从本地 npm 缓存恢复精确版本，不改依赖版本。
- 本轮不进行付费生成；不能将模拟请求验收宣称为真实供应商出片。

## 完成记录

- 模型入口现在明确列出 MiniMax H3、MiniMax H3 Max、Seedance 2.0、Seedance 2.5 和自定义；设置页支持按预设新增配置，也保留部署 ID / 中转模型别名。
- H3 / H3 Max / Seedance 2.0 / Seedance 2.5 的时长、分辨率、图片/视频/音频上限由同一能力表驱动，服务端 Provider 再次校验；普通 `MiniMax-H3` 不会误判为 H3 Max。
- 生成模式明确分为文本、严格首尾帧、多模态参考。多模态参考可混合人物、场景、物体、风格、开场、中段过渡、结尾画面、参考视频和参考音频；“中段”以提示词关系表达，不伪造不存在的 API role。
- H3 请求使用 `参考图片 1` 等自然语言关系；Seedance 使用 `@Image1` / `@Video1` / `@Audio1`。描述引导提供人物一致、推近、跟拍、固定镜头、动作顺序和声音氛围模板。
- 人物素材库可选择已有角色的多张图片，加入参考后会显示用途、说明和插入提示词操作。Electron 中本地图片预览通过 `readAssetDataUrl` 安全通道加载，避免 CSP 下的 `file://` 破图。
- QA：`scripts/qa-video-lab-models.py` 覆盖 1440/980 窗口、人物库、开场参考、Seedance 2.5 上限、`asset://` 视频、实际图片解码和横向溢出；深色截图已实看通过。`scripts/qa-video-lab-uploads.py` 的深浅主题四组也通过。
- 验证：9 个相关测试文件 293/293 通过，`npm run typecheck` 通过，`npm run build` 通过。构建前因本机缺失 `@esbuild/win32-x64@0.28.1` 暂时失败，随后从 npm 缓存恢复精确包，未改依赖声明或锁文件。
- 记录错误：文件化计划的第一次批量补丁因一处原文为“付费生成”而补丁上下文写成“付费视频生成”未匹配；拆分并按实际原文更新，没有重复错误操作。
- 仍不调用付费视频生成；本轮验证的是请求组装、约束、持久化和 UI 行为，不宣称供应商真实出片。
