# 图文与文章创作：平台参考核实

核实日期：2026-09-14。用途：为 StoryDream 的「图文笔记」「文章博文」设计提供参考。

本次只读公开一手入口及入口直接引用的公开前端资源，没有登录、上传或发布。下文严格区分本次实际观察与产品设计建议；设计建议不代表平台官方要求。

## 访问与核实边界

- 已加载 agent-reach 和 web-access skill，并执行环境检查。
- Agent Reach 未配置小红书后端及 Exa；Jina 公开网页路径返回匿名请求被拒绝。
- web-access 检查显示 Node 20、没有开启远程调试的浏览器；Codex 浏览器工具也返回没有可用浏览器。未更改浏览器或登录设置。
- 使用公开 HTTPS 页面源码及其直接引用的静态资源补充观察。页面标题、描述、公开资源中的菜单和组件文案可核实；不能据此声称已实际操作登录后的编辑器。
- 未核实各平台最新标题字数、正文字数、图片数量、图片尺寸、文件大小、话题数量等硬限制。不得把经验值标成当前平台规则。
- 未核实任何自动发布 API、发布权限或账号状态。产品原型应使用「导出发布包」「复制正文」等实际可实现行为。

## 四个一手入口

### 1. 小红书创作服务平台

来源：[小红书创作服务平台](https://creator.xiaohongshu.com/)。页面标题与元信息提到发布笔记、创作指导、数据分析等。

该入口直接引用的 [主资源](https://fe-static.xhscdn.com/formula-static/ugc/public/resource/js/index.a4c56181.js) 包含「上传图文」文案及进入发布页的导航；[发布组件资源](https://fe-static.xhscdn.com/formula-static/ugc/public/resource/js/project-publish-components.3c8a764e.js) 包含「请选择封面」「请先填写标题」「请输入封面文案」「封面优化建议」以及笔记封面预览组件。

**已观察：** 图文入口存在；封面与笔记标题有独立表达；存在封面编辑及效果预览相关组件。共享资源也包含视频逻辑，不能将每条素材格式提示直接解释为图文发布规则。

**设计建议：** 图文笔记以封面和内容页序列作为主要编辑对象。封面文案、发布标题、发布正文分开编辑，避免同一个字段同时承担三种职责。提供信息流卡片预览与逐页阅读预览。

### 2. 抖音创作者中心

来源：[抖音创作者中心](https://creator.douyin.com/)。页面元信息描述内容管理、互动管理、数据管理等服务。

入口直接引用的 [主资源](https://lf-fe-creator.douyinstatic.com/obj/douyn-creator-scm-cdn/douyin-creator-master-new/static/js/main.89aa82d2.js) 中可观察到「发布图文」导航及单独的图片上传应用入口，也包含「发布文章」菜单文案。

**已观察：** 图文存在独立发布入口。文章入口的实际开放范围、账号条件及当前可用性未核实。

**设计建议：** 本次抖音预设聚焦用户要求的图文模式，与小红书共用图片页、标题、正文的数据结构。增加全屏逐页预览和首屏安全区辅助，但将比例作为可选制作预设，不声称为平台唯一规格。音乐不设为必填，也不让图文创作依赖视频时间线。

### 3. 头条号

来源：[头条号](https://mp.toutiao.com/)。页面描述支持文字、图片、视频等多种内容形式。

页面公开导航配置中，创作包含「文章」及对应发布入口；内容管理分别列出「文章」「微头条」「PLOG」等，说明长文章和短动态是独立内容类型。

**已观察：** 文章具有独立创建和管理路径；微头条与文章不能当作同一个类型。

**设计建议：** 用户所说的「头条文章」进入文章工作台。采用标题、导语、章节正文、段内配图、文章封面的结构；未来如支持微头条，另加短动态预设，不让用户在长文章编辑器里猜测差异。

### 4. 百度百家号

来源：[百家号](https://baijiahao.baidu.com/)。页面描述其为集创作、发布、变现于一体的内容创作平台。

入口直接引用的 [公开介绍资源](https://now.bdstatic.com/store/v2/e8a15f8/fe-react-register/d4b73f5/static/js/main-9a8b795a.4684055a.js) 包含「多形态创作，图文视频尽显多元表达」。未进入登录后的文章编辑器。

**已观察：** 官方创作平台存在，支持图文等多种表达；本次不能核实文章编辑器字段细节和最新发布限制。

**设计建议：** 百家号与头条共用文章工作台，提供问题式标题、摘要、层级正文、图片说明及资料来源。答案前置、事实可追溯属于我们的写作建议，不描述成平台算法承诺。

## 具体工作流差异：产品建议

| 设计维度 | 图文笔记：小红书 / 抖音 | 文章博文：头条 / 百家号 / 通用博客 |
|---|---|---|
| 主要编辑单元 | 封面 + 有序图片页；每页包含文字与视觉说明 | 大纲 + 章节 + 段落 + 段内配图 |
| 标题 | 封面文案与发布标题分离 | 主标题与摘要分离 |
| 正文 | 发布说明、补充信息和行动引导 | 完整阅读正文，支持小标题、列表、引用 |
| 图片 | 逐页预览、排序、替换、单页重做；保留可编辑文字 | 封面单独选择，正文图片绑定段落并保留图片说明 |
| 话题 | 可编辑发布信息；不自动承诺话题有效或热门 | 栏目、关键词作为可选元信息，不把关键词当作正文 |
| 来源 | 素材出处、引用原文记录在资料面板 | 引用与资料来源可定位回相关段落，末尾可生成来源清单 |
| 预览 | 卡片首屏 + 逐页阅读 | 连续文章阅读 + 信息流封面卡片 |
| 导出 | 顺序图片、发布标题、正文与话题清单 | Markdown / HTML 正文、封面与配图、来源清单 |

## 对主设计的关键约束

1. 创作入口新增两个同级类型：「图文笔记」「文章博文」。进入后再选择平台预设；不为每个平台创建一个重复工作台。
2. 共用选题、资料和素材，保留独立的平台版本。修改小红书封面不应覆盖文章原稿；长文转图文生成新的派生版本。
3. 图文的 AI 操作围绕封面与单页，例如「压缩这一页」「换一个封面标题」「根据当前页生成配图」。文章的 AI 操作围绕大纲与段落，例如「重排大纲」「补充例子」「改写选中段落」。
4. 资料与来源从选题阶段就可用；不要等到导出时才收集。用户给定资料、模型建议和已核实信息应能区分。
5. 比例、页数、篇幅采用制作建议或用户设置。只有在后续拿到现行官方规则后才启用对应平台的硬校验，并记录规则来源及核实时间。
6. 当前原型若未接发布能力，主操作为保存版本、复制文案及导出发布包。不要展示虚构的账号绑定、发布成功或平台审核状态。
