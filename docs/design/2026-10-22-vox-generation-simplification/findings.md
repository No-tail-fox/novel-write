## 实施前研究（保留原始状态）

- Vox 使用 EditorialCollagePage + DirectorDeskWorkspace；检查器复用了漫剧导演台。
- 生成页同时出现制作配方、渲染策略和动画创作方式，属于不同抽象层。
- Remotion 分支的固定镜头页脚没有主生成按钮；生成动画、编译、导出散落在可滚动的编辑器内。
- 非 Remotion 分支有生成分层素材/关键帧/视频；整片生成和批量生成又是其他入口。
- 当前已有持久化批量计划，不能把“新增一个一键按钮”直接视为完整自动化已实现。
- 当前 1040×720 窗口实测检查器滚动区为 191px、内容 1257px，空队列和固定页脚挤占空间。最终十个状态没有整页横向溢出，不能泛化为横向破版。
- 批量执行器能力只包含 image/video/voice/render，排除 Remotion 画面/视频任务；动画生成、编译与预览检查未成为自动计划节点。
- 批量调度依附 React 工作区生命周期；恢复暂停并要求核对未知远端状态已有保护，但还不能承诺切页面继续后台制作。
- 内置生图工具不可用，按长期授权通过 VllmProxy 参考图编辑接口独立生成三张设计，实际截图均上传，返回 1536×1024，无本地放大或自动重试。
- GitHub 原文支持先改信息结构、单一主操作、逐步展开、诚实状态和滚动/焦点检查，不证明视频自动化本身成熟。
- 完整问题证据见 README；控件去留和状态矩阵见 interaction-spec；执行与样片门槛见 implementation-plan。
