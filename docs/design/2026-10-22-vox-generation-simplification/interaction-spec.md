# Vox 交互与控件规格

本文是完整目标契约，非全部已实现能力清单。2026-10-22 已按第三张完成阶段 A：制作大纲、旁白/画面描述就地编辑、高级抽屉、单一模板入口、固定项目生成区、空队列收起和按实际节点校验服务。它们沿用同一份项目状态。

三个制作预设、文案直接启动的自动链、后台运行与全链路恢复仍待阶段 B–E；下文的「一键生成成片 / 暂停制作 / 更新成片」完整状态矩阵是后续执行器契约。本阶段实际主按钮为「生成现有镜头成片 / 重新生成现有镜头成片 / 正在生成成片… / 批量制作进行中」，活动或无效状态禁用重复派发，另有「批量制作… / 查看制作任务」入口。详细状态和未验证项见 [acceptance.md](acceptance.md)。

## 1. 一个项目，两种操作深度

默认任务：提供文案 → 选择制作预设 → 一键生成成片 → 检查结果。

自定义任务：在同项目选择阶段或镜头 → 修改/锁定局部结果 → 更新受影响的成片。

- 首次进入：内联文案输入/导入、三个预设、画幅、旁白自动选择。“更多设置”默认收起。
- 有制作结果后：打开最近检查阶段和选中镜头；主操作位置保持一致。
- “逐步自定义”只改变展开状态和是否设置阶段检查点，不复制项目、不重建镜头。
- 未选预设的旧项目映射为“自定义”，保存原策略与模板；禁止静默重置旧项目。
- 项目设置保存画幅、旁白默认值、字幕样式、预设版本和输出规格；镜头编辑只修改本镜头。
- 不用“简单/专业”两套相互独立的数据模型。UI 保存展开状态，文档保存用户明确覆盖的值。

## 2. 默认预设

| 预设 | 默认解决的任务 | 自动决定 | 必要内容与边界 |
| --- | --- | --- | --- |
| 纸拼贴讲解（默认） | 概念、原因与解释 | 分镜、独立素材/抠图、主体与标签揭示、旁白字幕、模板分配 | 每镜头一个解释命题；需要的主体图必须真实可读；素材缺失则自动生成或提示修复 |
| 数据与地图 | 有真实数据的变化、对比、空间关系 | 对比/图表/路线模板、数字与地名排版、动作节奏 | 必须有数值/地理依据；缺失时给出补充数据或切回讲解的可执行动作，不编造统计或地理路径 |
| 档案叙事 | 有资料来源的时间/人物/事件讲述 | 档案卡片、引用强调、时间顺序、平稳转场 | 用户提供或经授权取得可用资料；AI 生成示意图不得伪装成真实档案证据 |

这些预设是“成片风格 + 规划策略 + 模板约束”的版本化组合，不直接等于现有 `EDITORIAL_RECIPES` 四个镜头配方。当前 `vox-narrated` 等可作为执行适配器；Paper Cut / gbro / Nantian 与渲染引擎不再并列成为新手必答题。

预设解析必须确定：规划提示/约束、所需能力、模板候选、素材策略、默认字幕/动作、可覆盖字段和缺输入行为。`auto` 必须可解析到实际已配置的模型/音色并形成运行快照，不能显示“自动”却在运行中要求用户挑选内部引擎。项目没有适用能力时在开始前解释精确阻塞。

## 3. 控件去留表

“移走”指退出默认画面，原能力继续有明确入口。不得用 CSS 永久隐藏功能后宣称完成。

| 当前控件/内容 | 默认处理 | 自定义入口/规则 |
| --- | --- | --- |
| 文案/主题、导入文稿 | 保留 | 文案阶段，可再次编辑并提示下游影响 |
| 大量写作/视觉风格候选、试生成 | 合并为三个制作预设 | 更多设置中的风格编辑；试生成明确标注范围与实际计费 |
| 每镜头“制作方式” | 预设自动分配 | 镜头高级设置中的“制作方法”，覆盖后标注已自定义 |
| 本地拼贴/图生视频/动画 | 自动选择 | 与制作方法同一处高级设置，避免配方与渲染策略相互矛盾 |
| 模板/AI 生成动画 | 自动选择可靠模板或生成策略 | 镜头高级中的创作方式；有修改提示时提供局部动作 |
| 模板预览下拉 + 选择模板按钮 | 合并成一个入口 | 可搜索、按镜头需求筛选、保留我的模板 |
| 镜头标题/旁白/画面描述 | 保留当前上下文 | 旁白与画面描述就地编辑；标题从旁白建议但可覆盖 |
| 来源、数字/条目/时间/地名 | 仅相关内容出现 | 模板 schema 决定字段；来源在引用/数据内容中保持可见 |
| 图片/透明主体/首尾帧 | 显示结果与缺失状态 | 素材步骤或当前镜头素材，支持替换、导入、锁定 |
| 音频频谱输入、GeoJSON | 不在普通镜头中展示 | 仅相应模板/图层需要时显示，原始数据放高级，必要输入不能藏到报错后才告知 |
| 强调色/背景色/文字色 | 预设默认 | 项目视觉设置；当前镜头明确覆盖 |
| Seed 与锁定 Seed | 不常驻页脚 | 素材高级；与“锁定人工编辑/镜头”区分命名 |
| 动效长目录 | 自动匹配 | 动效自定义按当前图层/镜头筛选，一个目录入口 |
| TSX 源码、检查代码 | 不默认显示 | 动画高级抽屉；打开后内容持久，焦点可返回 |
| 保存个人模板 | 移至模板库/镜头更多菜单 | 预览与校验通过后可保存 |
| 生成素材、生成视频、生成动画 | 新手无需分别触发 | 就地“重新生成此镜头”或阶段中的具体局部操作，使用次级样式 |
| 生成成片 | 提升为固定项目主操作 | 不依赖镜头类型、检查器 tab 或滚动位置 |
| 批量生成模态框 | 自动规划代替必填弹窗 | “查看制作计划”展开可修改范围/并发/阶段检查点 |
| 空生成队列 | 收起 | 有任务后操作条显示摘要，按需展开任务明细 |
| 预览/保存版本/导出此镜头 | 归位并明确对象 | 预览播放器；保存项目状态；镜头更多菜单导出 |
| 项目/集/镜头树 + 下方胶片条 | 避免双重镜头导航 | 设计 1 默认胶片条、项目树按需；设计 3 左侧镜头大纲替代胶片条 |

## 4. 页面和滚动

- 项目栏、制作导航、工作区、底部项目操作条分成独立布局行。主操作条不能作为检查器滚动内容的子元素。
- 桌面工作区允许源/大纲、预览与上下文编辑。精简镜头编辑首层最多三个语义组；进一步展开保留独立滚动。
- 1040×720 默认优先预览与编辑空间，不让空队列或 Seed 吞掉右侧底部。设计 3 在高度不足时让就地编辑区纵向滚动，预览按可用空间约束，不靠继续增高页面。
- 不硬编码整窗 `position: fixed` 覆盖全局 shell。操作条作为工作区网格底行，窄窗口文本可换行但主操作保持可见。
- ≤900px 面板改为单个可切换抽屉，保留既有路由；关闭、Escape 和焦点返回完整。抽屉应明示当前镜头；不出现同时遮挡画面的多个抽屉。
- 栅格/弹性容器 `min-width: 0; min-height: 0`，只为实际内容区设置滚动。固定条不遮住焦点和最后一行字段。
- 主题/尺寸沿用项目 token、13px 控件与 14px 正文、6px 圆角、Lucide 和 `src/ui`，不复用生图中的渐变、误字、装饰图标或任意尺寸。
- 深浅色、长标题/长错误、100 个镜头、键盘、200% 缩放均需覆盖；高密度编辑器不把桌面控件机械替换成通用移动端规范。

## 5. 固定项目主操作的状态

优先处理活动任务/未知远端状态，再处理当前输入的阻塞与成片新鲜度。仅通过一个可测试的状态解析器给出主按钮文案、动作、说明、禁用原因和次级操作；组件不能各自推断。

| 状态（按决策顺序） | 主按钮/行为 | 说明/次级操作 |
| --- | --- | --- |
| 正在提交计划 | 正在准备…，暂时禁用重复提交 | 同一运行 ID，防止双击创建两笔任务 |
| 运行中 | 暂停制作 | 展示真实阶段与已完成节点；取消为次级；异步阶段无可靠进度时不捏造百分比 |
| 已请求暂停、仍有在途任务 | 正在暂停… | 明示在途请求可能完成；待调度停止后才进入“已暂停” |
| 取消中 | 正在停止… | 停止后不删已完成产物，说明远端是否可取消 |
| 恢复时远端状态未知 | 核对任务状态 | 先按 provider job ID 查询/对账；无查询能力时显式处理未知结果，不自动重发收费请求 |
| 已暂停且状态已核对 | 继续制作 | 继续同一快照的未完成节点；完成/锁定结果复用 |
| 运行失败 | 重试未完成步骤 | 保留已完成节点，展示失败阶段、原因和“查看问题”；配置错误先导向具体修复 |
| 没有文案 | 填写文案 | 聚焦输入并给出内联提示，不把必需步骤藏在灰按钮里 |
| 文案不符合预设/能力缺失 | 补充数据 / 配置旁白 / 配置生图等 | 使用实际待执行节点判断；指出具体缺项，保留输入 |
| 可开始 | 一键生成成片 | 自动完成所有未锁定步骤；可先展开计划，无强制技术参数弹窗 |
| 当前快照已产出并验证 | 查看成片 | 主操作播放实际本地文件；下载/打开目录为次级 |
| 成片存在、输入已变更 | 更新成片 | 明示变更影响，仅重做失效依赖；保留上一版 |

取消、暂停、恢复和本地渲染必须分别依据执行器的实际能力；不得用切换 React 状态模拟已停止远端工作。主操作的暂停只暂停派发时，文案必须清楚告知这一点。

## 6. 自动与手动如何共存

- 每个产物保存输入指纹、依赖版本、执行策略/模型版本、provider job ID、输出校验状态。当前仅检查 `outputUrl` 是否存在，不能作为新设计的“成片已最新”判据。
- 编辑文案：重新规划受影响分镜、旁白/字幕、动画时间与最终片；修改颜色：重编排/渲染相关镜头，不重新付费生成不受影响的素材。
- 用户手动修改/导入可以锁定：锁定节点保留，若与上游变更冲突则解释冲突并让用户选择更新/保留，不能静默覆盖。
- “重新生成此镜头”只作用于明确范围；开始前说明会替换什么。运行时编辑创建下一修订或排队更新，晚到结果不能覆盖新草稿。
- 自动阶段检查点默认关闭。专家可选择“分镜后检查”“素材后检查”；这是计划选项，不应拆成另一套自动化产品。
- 进度与报错通过可访问状态区反馈；详细日志、内部引擎、费用节点进入任务明细。费用未知就显示未知，预估不能冒充账单。
