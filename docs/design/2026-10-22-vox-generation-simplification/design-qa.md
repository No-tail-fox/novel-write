## 生图方式

本会话搜索后没有可调用的内置 Image Gen 工具。按用户长期登记的付费渠道授权，使用 VllmProxy 的 `POST /v1/images/edits`，每次独立请求一张，模型请求值为 `gpt-image-2`，质量 high、PNG、1536×1024。没有静默改成 `gpt-image-2.5`，未使用只支持纯生成的 Image 2.5 helper。

每个请求实际以 multipart 上传了 [当前页面参考截图](evidence/desktop-current.png)，不是只写截图描述。凭据仅从进程/Windows 用户环境变量读取；未写入脚本、请求记录或聊天。保存了原始图像字节，无本地放大或改字。

| 聊天中展示次序 | 文件夹 | 返回实测 | 耗时 | 自动重试 |
| --- | --- | --- | --- | ---: |
| 1 | `concepts/preview-first` | 1536×1024 | 47.89 秒 | 0 |
| 2 | `concepts/guided-production` | 1536×1024 | 84.85 秒 | 0 |
| 3 | `concepts/process-outline` | 1536×1024 | 51.98 秒 | 0 |

三个响应都没有返回模型身份字段，无法据此验证上游模型身份。尺寸一致也不能证明服务端没有放大。公开价目表列出的 `gpt-image-2` 每次参考值为 0.02，三次为 0.06 个标价单位；不是经账单确认的人民币扣费。

可复核文件：`prompts/*.txt`、每个方案的 `request.json` 和 `metadata.json`、`generate-reference-design.ps1`。该脚本拒绝覆盖已有输出目录，单次调用没有自动重试或模型回退。脚本为本轮参考图接口适配，不是正式产品生成模块。

## 当前页面捕获的修正与范围

- 初始模板捕获未包含独立 Vox runtime，出现测试环境资源缺失。脚本补建当前 runtime 并等待 `data-vox-ready=true` 后已重跑成功；不把早期测试环境错误写成产品问题。
- 初始浅色捕获只切 provider，未同步 `html[data-theme]`，造成混色。已同步并重跑；最终深浅色证据以 `evidence/report.json` 对应十张为准。
- 关闭批量弹窗后等待其隐藏，再捕获紧凑窗口，避免把过渡残影误报为布局问题。
- 最终捕获状态为 `captured`，页面错误为空，没有记录到生成调用。构建和截图证明的是当前组件可以被测量，不是改版交互已经通过。

## 实施前约定（历史记录）

用户选定方案后再执行页面构建。先依照交互规格修正生成图的状态/文字/尺寸，再用同一状态和窗口的正式 Electron 截图做并列比较，检查层级、间距、裁切、滚动与焦点。三张独立方向不等于三个都要实现；最终仅形成一个连续工作流。

### 五项必检面与接受的差异

- 字体与排版：使用现有 13px 控件、14px 正文与 Segoe UI / Microsoft YaHei 回退，保留标题、字段、状态和辅助文字层级。长标题、紧凑窗口及 200% 缩放未见文本遮挡或异常压缩；生成图中的误字不作为正式文案。
- 间距与布局：来源左栏约 349px，正式桌面为 300px、紧凑为 248px，以保留真实桌面应用的编辑空间；≤900px 改用大纲抽屉。底栏桌面 92px、紧凑 80px；中央区、镜头列表和抽屉各自滚动，默认不保留右侧长检查器。
- 色彩与 token：沿用 StoryDream 珊瑚色主操作、深浅中性表面、6px 圆角和 Lucide 图标，不复制生图中的渐变、装饰阴影或疑似乱码状态。抽屉使用共享 overlay 层级，避免粘性标题覆盖操作。
- 图像质量与资产保真：来源预览近 2.35:1，实际 QA 项目是 16:9，正式预览以 contain 和必要留黑保留画幅，未为了匹配静态图裁切项目。参考城市艺术图仅作为隔离 QA 项目素材，四镜头缩略图复用它；正式应用仍显示各镜头实际资产。本轮没有据此声明动画画质或真实自动出片通过。
- 文案与内容：当前镜头为第 02 镜、15 秒位置，标题、旁白和画面描述匹配该镜头；不复制参考图的通用示例内容或假日期。主按钮为「生成现有镜头成片」，旁边保留「批量制作…」；完整自动链未完成前不使用「一键生成成片」承诺。

### 比较与修复历史

1. 保留草稿的关闭抽屉仍参与绘制，遮挡默认页面；已对关闭的 surface/backdrop 明确隐藏，并检查只有一套可见镜头导航。
2. 紧凑窗口主预览过高，挤压就地编辑；已按可用高度约束预览，并验证中央滚动和固定底栏。
3. 外部受控 Dialog 及嵌套模板目录关闭后焦点未可靠返回；共享组件已恢复外部触发按钮，Escape 只关闭最内层；漫剧定向回归同步覆盖。
4. 相同旁白提交曾使旧语音失效；更新函数已将相同文本视为无操作。真实修改仍撤销旧配音/对齐，测试覆盖同句数和重分配时序。
5. 首次截图遇到 Fluent 入场过渡，造成几何测量不稳定；QA 改为等待字体、有限动画及两帧布局稳定，没有关闭产品动画。
6. 窄窗口粘性标题遮住高级抽屉标题和关闭按钮；修复共享 overlay 层级后重拍，并添加 `elementFromPoint` 命中、实际点击和焦点返回检查。最终深浅主题窄窗口截图已复审。
