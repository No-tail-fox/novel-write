## 实际制作链

| 环节 | 风格生效方式 |
| --- | --- |
| 内容计划 | 只计划主体、动作、关系和环境，保持内容计划可跨风格复用。 |
| 生成素材 | 每种风格独立的材质、构图方向和三色配色进入实际生图输入。替换识别出的旧自动纸拼贴提示词；保留手工编辑的主体要求。 |
| 独立主体与去底 | 保持纯绿底、完整轮廓和留边约束；本地去底与边缘质量门控沿用现有链路。 |
| AI 动画 | 加载经 SHA 校验的上游风格、导演和技术参考，加入当前风格的运动语言、宿主范围、旁白时间与作者要求，生成 React/Remotion 代码。 |
| 检查与回退 | 保留编译、浏览器检查和最多一次代码修复；无法通过则使用当前风格的兼容模板与配色。 |
| 数据与档案 | 数据仍由有出处的数值与坐标驱动；档案仍使用导入的真实资料，切换风格不会改成无来源的生成记录。 |

旧项目的已保存描述可能包含纸张等旧表现方式。生成输入明确以新选风格控制材质与运动，沿用原主体、动作和构图，并保留真实物体属性；不会按关键词批量删除用户手工提示词。已有图片若直接复用，材质不会凭空变化，需在自动制作中生成新素材。

## 模板兼容的具体范围

全部 59 个风格具有制作配置，模板装配复用五类现有构图。它们不等于 59 套逐帧复刻的原作动画。

| 回退类型 | 图文流程使用的渲染路径 | 示例 |
| --- | --- | --- |
| layers | 旁白语义图层、原生标题、背景与主体分层 | 水彩、木刻、像素 RPG、赛璐璐 |
| focus | evidence-focus，聚焦主体后揭示说明 | 显微观察、新闻包装、档案灯台 |
| grid | gallery-grid，网格构图与顺序揭示 | 瑞士排版、倒计时、象形图 |
| space | gallery-space，空间布局与渐进展示 | 暗色发布、玻璃产品、工程拆解 |
| popup | paper-popup，纸景翻折 | 纸片立体书 |

只有 layers 使用语义图层时间轴。其他兼容模板不再被旧语义图层覆盖，且优先将主体而非空背景传入模板。数据与地图、档案素材流程保留对应的专业模板，再应用所选配色。AI 创作可在参考语法和当前宿主约束内进行更具体的编排。

绘画风格使用生成图片、遮罩与二维分层，不包含逐笔流体或颜料模拟；3D 风格使用图片、CSS 景深与视差，未新增 Three/WebGL 或物理材质引擎。实证、剪辑类风格不自动获得原始记录、真实测量或多机位现场声。这些适配说明显示在样片预览中。

## 缓存与续作

- 生图输入携带所选材质与适配版本，换风格会使相关图片输入过期。仅修改动画创作要求或代码模式可复用图片。
- 已运行任务使用其固定设置；空闲时优先读取新保存设置，避免旧的已完成任务覆盖新选择。
- 内容计划哈希不包含动画风格与作者动效要求，避免仅换风格就重复付费规划。
- 动画节点使用适配版本 2 和固定上游版本，旧动画会重新检查。付费请求的持久化凭据与结果不明暂停规则保持有效。
