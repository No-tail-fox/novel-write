# 创意动画风格封面与官方样片预览

新建项目的“动画与风格”步骤，以及项目内“自动制作设置”，共用可预览的视觉风格选择器。沿用图片设置的 `PreviewSelectField`：下拉选项显示缩略图，选中后在字段下显示封面与风格名称，支持悬停放大和点击播放参考样片。

## 使用方式

- 自动匹配与全部 59 种风格均显示本地缩略图。鼠标悬停下拉选项，或用键盘移动高亮选项，显示对应官方大封面；预览不改变选择、不触发视频播放和制作。
- 收起下拉列表后仍能看到当前选中封面；封面与样片播放前的海报均使用打包资源，不依赖官网图片加载。
- 选定风格后点击“播放样片”，在应用内打开视频预览。使用原生播放、暂停、音量、进度和全屏控制，不自动播放，视频 `preload="none"`。
- “自动匹配”随素材流程解析为实际风格，并在预览里注明当前匹配结果。模板装配按所选风格生成素材，使用所选配色与现有兼容动效。
- 加载失败提供重试；重试后焦点留在视频。关闭预览后焦点返回播放按钮。离开页面、切到后台或打开官方网页时暂停视频。
- 视频全屏时第一次 Esc 只退出全屏，再按 Esc 关闭预览；嵌套预览关闭后保留制作设置。
- 提供一个“查看 Lemo 全部 59 种风格”入口，使用现有受控外链 API 打开系统浏览器。

## 已核实的官方来源

- 项目：<https://github.com/lemomo-ai/lemo-opuscar>
- 样片库：<https://lemomo-ai.github.io/lemo-opuscar/>
- 页面核验日期：2026-10-25。官方页面有 59 个风格条目，每种配有静帧与影片。不要与另一个 OPUSCAR 长片风格目录混淆。
- 从实际页面提取资源路径：封面为 `img/<slug>_0.jpg`，视频为 `films/<slug>.mp4`，均位于官方样片库目录下。
- 59 种风格均有本地封面与官方视频地址映射；名称只接受本地目录中列出的 slug，不拼接任意输入。当前回归逐一验证真实本地封面，视频交互使用离线媒体替身，未逐一联网验证 59 支影片。

制作选项已扩展为“自动匹配 + 59 种风格”，按官方 11 个分类分组。每种风格具有生图材质、配色、动画代码语言与兼容模板配置。详见 [制作适配与验收](2026-10-25-creative-styles-production.md)。

## 媒体与许可

官方说明区分 MIT 代码/文档与 CC BY 4.0 样片/静帧。59 张官方静帧等比例缩小至不超过 768 × 432 并转换为 WebP，未裁剪；总计 2,251,742 字节，约 2.15 MiB。来源、尺寸、改动、原图与预览 SHA-256 记录于 `src/assets/creative-style-previews/manifest.json`，完整许可位于 `THIRD_PARTY_LICENSES/CC-BY-4.0.txt`。预览显示 LemoLab 署名、仓库链接、许可和封面改动说明。`game-show`、`paper-lantern`、`news-package` 额外注明原片配音不在此许可内。制作不复用任何官方原片音轨。

本次没有改写 `vendor/lemo-opuscar` 中固定版本的文本参考和校验清单。封面随安装包分发，普通构建不联网；影片、音频和原片配音不加入安装包。官方样片按需联网播放，失败时提供说明、重试及官网入口。生产 CSP 的 `media-src` 仅增加 `https://lemomo-ai.github.io`，不放开任意远程视频或脚本。

官方影片展示风格参考，实际输出仍由用户文案、所选模式和现有制作链生成。本次没有把参考样片作为本应用新生成成片的质量验收。
