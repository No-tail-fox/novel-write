# AI 漫剧：项目资产与分集制作

日期：2026-10-22。

## 设计决策

项目顶层分为「分集制作」与「项目资产」。资产属于整个项目，不作为某一集制作流程中途才出现的步骤。人物、地点、道具和系列设定可在生成分镜前访问、编辑，后续集复用同一份定义。

分集制作保留现有七步流程。剧本工作台采用分集列表、幕场目录、当前场正文三个区域，各自负责滚动；梗概默认折叠，底部审核操作与正文滚动分开。紧凑桌面窗口保留可用的幕场目录和正文高度。

项目资产使用分类、搜索、资产列表和选中项详情。详情以资产名称为标题，显示稳定身份 ID 和跨集引用；人物优先展示造型与参考图，人物定义、别名、性格与配音可展开编辑。参考图生成服务和当前集参考检查默认折叠，为列表保留空间。

参考图支持大图预览、版本缩略图、固定及取消固定。切换预览不会改变固定版本，文件读取成功后才能固定；缺失文件展示错误与重试。宽窗口并列展示参考图和视觉定义，紧凑窗口上下排列，图片完整显示。

跨集引用按稳定 ID 汇总已确认剧本与正式分镜，同一集只显示一次。点击引用可进入该集剧本或分镜；加载或读取失败时保留正式分镜引用，支持重试。旧版或已失效的剧本批准记录不计入已确认引用。跨集跳转保留尚未保存的资产编辑。

## 最终流程

原文与分集计划 → 单集剧本及人物/地点/道具提取 → 审阅剧情与项目身份映射 → 批准剧本并保存项目资产 → 单独生成、审核并应用分镜 → 固定视觉参考就绪 → 媒体生产。

资产可以在项目资产区提前建立，也可以随单集批准补充。当前实现是逐集提取和跨集复用；未新增整部小说一次性全剧资产预提取。

文字身份确认与固定参考图是两个检查点。前者在分镜生成前完成，后者在媒体生产前检查，不因文字定义存在就视为视觉参考已就绪。

## 全局素材库

全局素材库保存跨项目复用的图片、文本与提示词，并接通图片创作、文案创作、对话和漫剧项目资产。漫剧采用素材时创建项目自己的参考图副本和固定版本，保留来源 ID 与内容 revision；回收原素材不影响已采用内容。详见 [素材库设计与验收](asset-library-acceptance.md)。

## 身份复用规则

- 显式选择项目 ID 时，以该 ID 为准。
- 自动匹配采用 NFKC 规范化后的名称和人物别名精确匹配，不做模糊身份合并。
- 无匹配时可创建独立身份；多个匹配时阻止批准，要求明确选择。
- 人物造型只在所属人物内匹配；已删除身份、归属错误的造型和同时新建/复用的冲突均拒绝。
- 复用资产保留项目统一定义、既有参考和声音，不以新一集候选内容覆盖。
- 批准将映射后的 ID 与项目资产一并持久化；分镜生成和应用再次校验。
- 历史批准记录如果没有资产确认标记，需重新确认后生成分镜。
- 旧版规划弹窗也在分镜模型调用前保存已确认资产，失败重试沿用已分配的身份。
