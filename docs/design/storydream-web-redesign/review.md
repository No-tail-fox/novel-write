## 建议保留

1. 项目外只有六个入口：项目、素材库、灵感、模板、任务、设置。VOX、漫剧、HTML 动画和 MV 在新建项目里选择。
2. 项目内用返回入口、标题、保存状态、预览/导出组成顶栏。下方以文案、分镜、声音、交付组织工作流。
3. 当前编辑对象有单一选中状态，左侧定位、中间预览、右侧修改；高级参数默认折叠。
4. 用真实缩略图帮助识别项目；参数页采用分区与分隔线，避免多重卡片。
5. 中性浅灰白与石墨文字为主，珊瑚用于关键操作及选中，蓝/绿等只承担轨道与状态语义。

## 实现时仍需细化

- 最终桌面编辑器采用横向工作区，概念图的方形画幅仅展示各区域关系。
- 图片里的时间轴数字不是逻辑规格；继续使用现有权威 playbackMs 和真实片段时长。
- 单个区域仅保留一个主按钮，进一步降低图中多个珊瑚按钮同时出现的权重。
- 基础正文 14px、辅助 12px 起，图像中文字大小不能直接照搬为 CSS。
- 工具与导航继续使用 Lucide；生图的 S 标记不直接替代产品品牌资产。
- 远程 Web 的本机连接状态来自已验证连接；仅填一个地址不能宣称已连接或获得本地能力。

## 已落地的基础与边界

- 共享壳层首次整理：窄屏导航可滚动，浏览器隐藏桌面窗体按钮，减少重复底部信息，补充选中语义。
- Light theme 的 CSS tokens 与 Fluent 配色对齐；已有用户明暗偏好未自动迁移。
- 新增 `npm run dev:web`；本轮本地预览位于 `http://127.0.0.1:5186/`。
- 现有 Web 仍使用 fallback；它不能真实执行本地流水线。连接器 API、项目首页的六入口导航和编辑器阶段切换尚未按概念图迁移。
- `runtime-capabilities.ts` 是未接入业务流程的准备模块；配置地址或 token 不授予本地能力，正式 adapter 必须完成鉴权握手后再扩展。

## 生图请求处理

- 专用生图 helper 前期存在 502/503、连接中断；新凭证的 gpt-image-1 路由返回不支持。
- Windows PowerShell 请求字符串可能丢失中文，读取的字符串额外属性也可能干扰 JSON。项目脚本改用明确 string 类型与 UTF-8 字节提交后成功返回中文设计图。
- `scripts/generate-storydream-design.ps1` 从当前进程的 `INPUT_IM_API_KEY` 读取凭证，日志只记录不含密钥的状态。没有将用户凭证存入仓库。
