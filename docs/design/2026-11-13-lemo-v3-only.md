# Lemo 制作统一为 v3

2026-11-13。

按用户要求，停止旧 Lemo 制作任务的执行、恢复和迁移，不再为旧任务维护 v1/v2 制作链。原任务数据和素材不删除。

当前原生制作仅通过 upstream Agent 执行：配音与校时 → 逐轮文件操作与审片 → 当前源码检查 → 渲染 → 媒体验证。模型入口仍为配置的文本模型与 StoryDream 自有 Agent；此次改动没有将官方 Claude Agent SDK 接入生产。

移除旧规划、固定 shared/scene/director 文件生成、增量补丁执行、旧规划升级、旧代码重检，以及相关宿主模型回调。新建原生任务要求 v3 runtime；显式旧版本执行请求拒绝执行，应用启动恢复跳过旧 Lemo 记录，不写回迁移。现有 v3 的暂停、继续、失败重试、预算恢复与回执核对保留。非 Lemo 的预设动画制作不受此版本退役影响。

数据 schema 与现有素材的编译/读取辅助仍保留，避免读取项目时丢失内容；它们不再连接旧制作执行器。专属于退役流程的测试与提示词配置移除，混合测试保留编译、旁白、锁定镜头、当前 Agent 与通用界面的覆盖。

验证使用离线模型与隔离测试，不触发用户项目生成或付费模型调用。构建产物已更新，运行中的桌面进程仍需重新启动才能加载新的主进程代码。
