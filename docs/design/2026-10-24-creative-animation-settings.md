# 创意动画参数与高级设置收敛

本次修复创意动画合并后新建仍停留在旧 Vox 图片风格、版式、相机预设的问题，同时简化镜头高级设置并修复全屏退出。

## 新建与自动制作

新建沿用已确认的三步流程：内容与画幅 → 动画与风格 → 声音与输出。项目内的自动制作设置与新建共用 `CreativeProductionFields`，写入相同的 `productionSettings`。

| 参数 | 行为 |
| --- | --- |
| 制作方式 | 默认 AI 创作；也可选模板装配。后者不调用代码生成模型。 |
| 视觉风格 | 自动匹配，以及按 11 个类别分组的 59 种风格，支持封面与官方样片预览；2026-10-25 已补齐全部制作适配。 |
| 素材流程 | 自动生成图文素材、真实数据与地图、档案资料。后两者按需显示真实输入、来源与许可字段。 |
| 动画创作要求 | AI 创作时可选填，最多 2000 字符，进入代码生成和修复提示词，保留原旁白。 |
| 声音与输出 | 保留旁白开关、音色和字幕样式；画幅和时长在第一步设置。 |

图片服务和 Seed 收进“生成服务与素材一致性”。项目设置分别提供“保存设置”和“开始自动制作”；保存本身不触发生成。数据或档案尚未补齐时可以先保存基本设置，但不能开始自动制作。改变创作要求会重新生成对应代码，复用已批准的制作计划。

风格目录中的 59 个参考条目均已接入制作。自动匹配仍按素材流程选择默认风格；手动选定的风格进入生图、动画代码与兼容模板配置。当前适配范围及验证限制见 [全部风格制作适配](2026-10-25-creative-styles-production.md)，预览交互见 [风格封面与样片预览](2026-10-25-creative-style-previews.md)。

## 镜头高级设置

普通入口合并为“画面与动画”“声音与字幕”两组。图层与运动关键帧、素材制作与生成服务、镜头与节拍结构、背景音乐与音效按需展开。镜头时长保持可见，模板配色细节、复用和导出操作收进折叠区域。版本记录、审片和旧深链接仍保留。

共享导演台中的 AI 漫剧继续使用原有页签结构，既有路由和数据标识不变。

## 全屏

镜头预览与当前成片统一由预览容器管理全屏状态。按钮随状态显示“全屏 / 退出全屏”，支持 Esc 和双击预览切换。全屏时保留退出入口，并按可用高度容纳画面与控制栏。
