# StoryDream 图文与文章创作设计

日期：2026-09-14。交付：沿用现有桌面工作台的可交互原型与正式接入方案。

## 1. 产品定位

在现有视频创作之外增加「图文笔记」「文章博文」两个同级入口。用户先决定作品形态，再选平台、提供资料、完成创作。一个主题可以衍生多个作品，每个作品有独立的平台版本。

这两类入口加入现有「新建任务」的制作类型，并出现在「项目」下的创作工作区。现有智能成片、VOX、漫剧、HTML 动画、音乐 MV 的入口和顺序保持稳定。项目库筛选新增图文笔记和文章博文。

| 创作类型 | 首批平台预设 | 主要产物 |
|---|---|---|
| 图文笔记 | 小红书、抖音图文 | 多页图片、独立发布标题、配文、话题 |
| 文章博文 | 今日头条、百度百家号、博客 / 网站 | 标题、摘要、章节正文、封面与插图、引用 |

微头条属于短动态，后续可增加专门预设；不混入长文章。平台选择是创作偏好的集合，不代表已绑定账号或可直接发布。

## 2. 共用创作流程

1. **选择形式**：图文笔记 / 文章博文，选择平台，选空白创作或模板。
2. **创作简报**：主题、读者、目的、语气、篇幅 / 页数；输入可以是选题、已有文案、本地资料或链接。
3. **整理资料**：从灵感热榜带入标题、摘要、已获取正文与来源。用户能看出哪些资料未取到正文，哪些事实需要补充确认。
4. **结构与初稿**：AI 先给可编辑的大纲或分页面规划；用户可以改顺序、删减、补充，然后生成正文与配图建议。
5. **排版与修改**：在内容所在位置调用 AI；保留原文，展示修改候选与差异，确认后应用。
6. **平台版本**：基于母稿创建平台变体，分别调整标题、文字密度、封面和话题。切换仅切换当前版本，绝不隐式重写。
7. **检查与导出**：检查缺失内容、画面溢出、图片来源及未处理引用，再复制文字或导出完整素材包。

全局只有一个主动作与当前阶段对应：生成结构 → 生成初稿 → 导出作品。生成需要明确资料范围；模型调用失败保留已完成结果，并能只重试失败页 / 段落。

## 3. 图文笔记工作台

采用「页面列表 | 当前页画布 | 页面属性」三栏。左侧按成品顺序显示封面、内容页、结束页；中央画布获得稳定最大空间；右侧仅显示选中页的内容。

### 页面与配文

- 页面字段：角色（封面 / 内容 / 结尾）、页眉标签、大标题、正文、配图、版式、素材来源。
- 首张图为封面，可由其他页面复制创建。发布标题和封面大标题是两个字段。
- 配文单独编辑发布标题、正文、话题，不与图片文字绑定。
- 操作：新增、复制、删除后撤销、拖动排序，以及键盘上移 / 下移。页面按稳定 ID 选中，顺序变化不丢选择。
- 图片：素材库选图、导入本地图、AI 配图；文字保持可编辑图层，避免把中文正文直接烧进生成图片。
- 图片属性提供裁切、适应、焦点、替换、说明和来源，复用已有素材能力。

### 模板方向

| 方向 | 页面组织 | 适合内容 |
|---|---|---|
| 清单手册 | 短标题 + 编号 + 一页一个重点 | 教程、整理、经验、知识卡片 |
| 留白文字 | 留白 + 清晰段落 + 克制页眉 | 书摘、观点、随笔、情绪表达 |
| 重点提案 | 强标题 + 主题色 + 行动要点 | 方法、对比、建议、选品 |
| 照片日记（后续） | 大照片 + 简短注释 | 旅行、美食、生活记录 |
| 对比讲解（后续） | 成对画面 + 差异标注 | 测评、前后对照、选购 |

3:4、9:16、1:1 是可选制作比例，不作为未经核实的平台硬规定。整组应用基础样式，允许单页覆盖；改变比例后提示检查文字溢出和图片裁切。

### AI 应作用在具体对象上

- 简报：规划内容节奏，生成 3 个封面标题候选，给出每页的一句话重点。
- 当前页：精简文字、拆成两页、补一个例子、根据内容建议配图。
- 整组：检查重复信息、统一口吻、改编为另一个平台版本。
- 结果先出现在候选区；用户明确应用后才修改作品。批量生成显示成功 / 失败页数，不使用模拟进度。

### 预览与导出

信息流预览检查「封面 + 发布标题」，逐页预览检查阅读节奏。模拟阅读效果应标明是预览，不伪造账号、点赞、热度和发布成功。

正式导出目录：`images/01-cover.png`、`images/02-content.png`…，以及 `caption.md`、`sources.json`、可重新编辑的项目文档。可选 PNG / JPG、分辨率和图片质量，按内容顺序命名。批量渲染过程中锁定导出版本，避免导出的不同页来自不同编辑状态。

## 4. 文章博文工作台

采用「提纲 / 资料 | 正文 | 上下文工具」三栏。连续正文是正式编辑器主模式，提纲点击定位当前章节；选中段落才出现对应的 AI 与图片工具。

### 内容能力

- 独立的文章标题、摘要 / 导语、封面与正文。
- 原生结构化块：段落、二 / 三级标题、列表、引用、图片与说明、分割线。
- Markdown 导入导出；粘贴清洗保留语义，避免平台复制进来的脏样式。
- 图片绑定稳定段落 ID，调换段落时图片与说明一起移动。
- 左侧资料条目可插入引用；正文引用可回到来源原文位置。无法核实的事实标记为待核实，不能由模型补造出处。
- 显示字数、阅读时长估算、大纲层级；光标和滚动位置在切换资料、预览后恢复。

原型用共享文本控件演示按段落编辑和连续阅读，**尚不是富文本编辑器**；正式实现需要块编辑器、撤销历史、粘贴清洗、链接与图片支持。

### 平台表达预设

| 平台 | 默认表达建议 | 预览 / 导出重点 |
|---|---|---|
| 今日头条 | 核心观点明确，导语进入问题，案例支撑观点 | 阅读预览、封面图、栏目、正文 |
| 百家号 | 具体问题式标题，答案前置，来源可追溯 | 摘要、图片说明、参考资料 |
| 博客 / 网站 | 稳定标题层级、目录、分类、可持续更新 | Markdown / HTML、目录锚点、摘要 |

上述是产品写作建议，不承诺平台推荐、收录或流量。不默认添加夸大标题、虚构个人经历、捏造案例或无来源的数据。

## 5. 一稿多用与版本

- 作品之间使用 `sourceDocumentId` 关联；平台版本使用独立 `variantId`、`revision`、`derivedFromRevision`。
- 「长文拆图文」先给页结构：封面 → 关键问题 → 逐页要点 → 总结；用户选择采用的章节与页数。
- 「图文扩展文章」先给提纲，说明哪些图片文字需要补充解释，再生成段落。
- 正式改编创建新的派生作品，不覆盖已有目标。引用和图片来源随内容带入。
- 母稿更新只标记“母稿有新版本”；展示差异并由用户选择同步范围，不自动覆盖手动编辑。
- 平台变体有自己的标题、配文、图片顺序、分类。切换平台与生成改写是两个动作。

原型为了演示结构转换，会在确认对话框后替换一个目标示例版本，保留当前来源；界面明确说明这一边界。正式产品必须创建新作品。

## 6. 接入现有项目

### 导航与项目

增加 `graphic-note`、`article` 两种创作类型与独立路由。涉及 `TaskCreationTypePicker`、`productionNavItems`、`ShellView`、路由注册、AppRoutes、项目筛选、`taskWorkspaceView` 及 IPC 查询类型枚举，必须成套接入，避免只能新建不能重开。

共用统一 `tasks` 记录及项目收藏、归档、分页。文档持久化带 `schemaVersion`，保存带 `expectedUpdatedAt` 防止旧请求覆盖新版本；编辑页接入已有未保存离开保护。

### 文档结构建议

```ts
type ContentDocument = {
  id: string;
  kind: 'graphic-note' | 'article';
  schemaVersion: number;
  brief: CreativeBrief;
  sources: SourceRecord[];
  master: NoteDocument | ArticleDocument;
  variants: PlatformVariant[];
  sourceDocumentId?: string;
  createdAt: string;
  updatedAt: string;
};
```

图文页使用 `id / role / layers / layout / assetRefs`；文章块使用 `id / type / content / assetRefs / sourceRefs`。平台能力另建专用类型，不复用当前视频语义的 `ContentPlatform`。生成结果用结构化 schema 校验；失效资产和未知版本提供明确错误恢复。

### 复用边界

- 复用现有 `searchWebSources`、`readHotBoardSource`、图片生成 / 素材库与 LLM 配置。
- 扩展结构化写作 API；现有 `composeResearchCopy` 只返回标题和文案，不能当作已有图文分页或引用生成能力。
- 热榜「去创作」增加形式选择，携带同一份已获取资料；保留正文缺失与读取警告。
- 复用 `src/ui` 包装控件、主题、Lucide、工具条与 Pane。不得从功能页直接引入 Fluent。
- 不直接复用视频草稿模板的数据模型；可复用画布几何和图片裁切逻辑。图文不依赖配音、字幕、时间线或剪映。

## 7. 状态与检查

| 情况 | 产品处理 |
|---|---|
| 没有内容 | 展示简报入口与空白创作，不伪装已有项目 |
| 模型未配置 | 可手动创作；AI 按钮说明配置入口 |
| 单页生成失败 | 留下其他页面，失败项可单独重试 |
| 请求期间继续编辑 | 生成结果保存为候选，不覆盖更新后的正文 |
| 文字超出画布 | 标出对应页面，建议精简 / 拆页 / 改版式 |
| 保存失败 | 保留内存草稿，提供重试和文件备份 |
| 资料链接失效 | 留下已保存正文与来源记录，提示重新获取 |
| 切换平台 / 返回项目 | 保留编辑、选中页 / 段落、预览位置 |
| 导出部分失败 | 明确缺失文件，允许补导，不能宣称完成 |

1440 宽保留三栏；1040 宽收紧全局侧栏和缩略图；更窄时页面列表可展开，属性区移到画布下方。键盘能选择、移动、预览和导出；图标按钮有名称，当前状态不只靠颜色表示。

## 8. 实施顺序与交付边界

**第一阶段：可持续使用的编辑与导出。** 两类项目新建 / 保存 / 重开，图文文字图层与素材、文章块编辑、平台版本、预览、整组图片 / Markdown / HTML 导出。这一阶段就能手动完成作品。

**第二阶段：接入 AI 与资料。** 简报到结构到初稿、单页 / 段落修改、配图、引用检查和一稿多用。使用已有配置，模型任务进度进入统一任务系统。

**第三阶段：模板与分发。** 模板库、品牌样式、批量平台适配、更多输出格式；平台直发仅在核实能力并独立设计账号和发布确认流程后考虑。

本次完成的是可交互原型与方案：页面 / 段落编辑、顺序调整、复制、平台版本、版式、比例、预览、浏览器保存、HTML / Markdown 文件下载。尚未接入生产路由、数据库、模型、图片生成与平台发布。

原型不使用用户真实项目或凭据。公开平台依据与未核实项见 `../../plans/2026-09-14-content-platform-references.md`。
