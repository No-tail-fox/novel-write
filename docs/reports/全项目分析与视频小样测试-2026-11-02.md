# StoryDream 全项目分析与视频小样测试

日期：2026-11-02。范围：项目入口与主模块梳理；普通短片、HTML 动画、创意动画、音乐 MV 各一份本地小样。未改产品源码、用户项目、配置或上游固定资源；模型付费请求为 0。

## 项目全景

StoryDream 是 Windows Electron 桌面创作工作台。产品不是单一视频生成器，而是把选题/文案、素材、配音、分镜、字幕、时间轴、预览、渲染与交付组合成若干不同的制作流程。新建入口在 `src/features/tasks/TaskCreationTypePicker.tsx`，导航表在 `src/app/route-registry.ts`，制作项目统一出现在项目/历史页。

主要创作面包括：

- **普通短片**：文案与分镜、图片/本地视频素材、配音、字幕/BGM、模板、MP4 与剪映草稿；Pixelle 是同一短片交付链的一组固定 HTML 模板。
- **HTML 动画**：按场景组织文案、素材与声音，可编辑场景/组件，生成预览并输出 MP4。
- **创意动画（VOX/Lemo）**：导演式分镜、动画模板与代码镜头、图层/素材、字幕与声音、审片、创作/修复与 MP4 输出。普通 VOX 动画及官方 SDK v4 新生产入口共享部分导演渲染能力。
- **AI 漫剧**：系列设定、源文拆集、剧本/分镜、角色与参考资产、对白/配音、视频镜头与成片，是独立于上面三种短片方法的长流程。
- **音乐 MV**：歌曲和歌词驱动的场景规划、节拍/字幕时钟与视频合成；页面独立，但复用导演时间轴和渲染底层的一部分。
- **配套工具**：图片、配音、视频和音乐创作实验室，文案工作台、热点/爆款分析、图书选品、素材库、模板、任务队列、项目历史、模型/渠道设置。

工程采用 React + TypeScript renderer 与 Electron 主进程，`src/shared` 放跨界面/主进程的领域数据、schema、时间轴和制作规则，`electron` 绑定 IPC、项目存储、渠道、任务运行与导出；项目也使用本地 SQLite/sql.js、Python 媒体 sidecar、FFmpeg 和 Chromium/Electron 浏览器捕帧。普通短片、HTML 动画、导演/创意动画有不同的生产入口，但底层共享部分媒体检查、字幕布局、取消/任务状态和 FFmpeg 能力。

结构上的优势是不同作品可以保留所需的生产模型：可编辑剪映草稿适合普通短片，HTML/代码适合确定性动效，导演流程适合多镜头叙事，MV 则可以围绕歌词节拍。对应代价是多个生产入口、时间轴与导出状态并存；`electron/main.ts` 承担较多 IPC/运行时接线，因此跨流程改动需要针对真实输出做回归，不能只依赖通用单元测试。

## 当前成熟度判断

本轮证明四种路线的本机渲染、音视频容器、字幕/时间轴和代表性交付链有工作路径。普通短片在交付方面最完整：MP4 和剪映草稿均有真实文件检查；HTML 动画适合组件/文字驱动的解释片；创意动画能将模板、代码和图层镜头混合；MV 对歌词时序做了帧级约束。以上是工程可用性判断，不是四种方式的内容质量排名。

更广范围的同日项目记录还显示：Pixelle 的 31 个固定模板和 6 个扩展情况完成 37/37 双输出/排版检查；官方 Lemo SDK v4 有独立本机夹具整片与恢复测试；全仓当日最终回归记录为 4,927/4,927、四套 TypeScript 检查通过。详见 [当日收尾与验收记录](../plans/2026-10-24-creative-animation/remaining-work-closure-2026-11-02.md)。这些属于已有独立记录，本轮没有重新运行全仓回归。

尚未闭环的决定性事项是作品本身与外部生产条件：当日收尾记录显示当前配置没有 Messages 模型能力配置和 Pexels Key；真实图像请求曾返回 HTTP 403，火山配音单项真实请求成功但不等于整片通过。真实原创视频的美术/叙事、完整听审、多风格长片、剪映应用实开、干净 Windows 安装和已授权生产环境均需另外验收。安装包已构建但没有运行安装器，且发行物未签名。小样中的程序色条、渐变与测试音，不能替代这些验收。

## 下一步建议

先用同一主题制作 15–30 秒真实内容对照：普通短片用真实授权素材和旁白；HTML 动画做信息图式解释；创意动画做叙事/风格镜头；MV 使用真实授权歌曲与可靠歌词时间戳。每条只做 2–4 个镜头，并人工看关键帧、看完整视频、听音频，记录耗时、真实请求数/成本、改稿次数与可交付性。再选择一条主路线做更长样片；目前不建议凭这四份工程夹具决定哪种成片观感最好。
